# Skills

Reusable agent skills for software discovery, architecture, technical planning,
implementation, orchestration, deep review, and Rust development.

## Install

List the available skills:

```bash
npx skills add juliosouzam/skills --list
```

Choose skills interactively:

```bash
npx skills add juliosouzam/skills
```

Install a specific skill for Codex:

```bash
npx skills add juliosouzam/skills --skill tech-lead --agent codex
```

## Available skills

- `deep-review`
- `grill-me`
- `prompt-enricher`
- `rust-best-practices`
- `software-architect`
